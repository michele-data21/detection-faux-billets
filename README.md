# Projet 12 – Détection de faux billets

## Objectif
Développer un modèle de machine learning permettant de détecter des faux billets.

## Compétences développées
- Machine Learning supervisé
- Machine Learning non supervisé
- Random Forest
- KNN
- K-means
- ACP
- Analyse exploratoire

## Outils
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

## Livrables
- Notebook d’analyse
- Script de prédiction
- Support de présentation

## Résultats
Le modèle Random Forest obtient les meilleures performances.
